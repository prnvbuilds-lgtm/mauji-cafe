# Mauji Time Café & Spaces

A responsive website for Mauji Time Café & Spaces—an anti-café, co-working hub, and creator community. Guests pay for the time they spend in the space while enjoying beverages, Wi-Fi, and welcoming places to work, meet, and create.

## What’s in this repository

- A responsive React single-page application with pages for the café, co-working, spaces, events, pricing, bookings, and Mauji’s story.
- An AI concierge and interactive booking, pricing, and time-calculator experiences.
- Mauji brand content, location details, event data, and image assets.
- A Vite production build configured for fast, code-split delivery.
- A GitHub Actions workflow that builds and deploys the site to GitHub Pages.

## Built with

React, Vite, React Router, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal. To test on a phone connected to the same Wi-Fi, use the network URL printed by Vite.

## Production build

```bash
npm run build
```
